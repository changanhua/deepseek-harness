# DSH 收藏

[English](README.md) | 中文

这是可直接从 Chrome 的“加载已解压的扩展程序”加载的 Manifest V3 目录。它不需要构建、`package.json` 或新增依赖。

## 日常收藏

在 HTTP(S) 网页中选中文字，右键选择“收藏选区到 DSH”。在 ChatGPT 或知乎打开一次扩展，启用该网站快捷入口，即可在回复或回答旁保留收藏按钮。完整回答采集拒绝已识别的生成中或折叠状态；无法确认回答正文或直达链接时，改用选区收藏。采集范围为文本，不下载图片和附件。

默认 DSH 地址为 `http://127.0.0.1:3080`。首次保存会打开 DSH 请求显式批准，随后继续保存同一份内容。服务地址和安装授权都会记住。工具栏图标始终打开阅读侧栏，连接设置收在齿轮按钮中。仅在使用其他端口或服务器时修改地址。地址必须是 HTTP(S) origin 根路径，不支持部署路径前缀。

manifest 请求本机服务访问权限和选区右键菜单。ChatGPT 和知乎的持久页面权限可选，只有用户启用网站快捷入口时才请求。页面监听只安装按钮，采集与发送由用户选区或点击触发。批准只授予内容导入权限，不复用用户的 Web 会话。令牌和 verifier 保留在扩展受信任存储中，不返回给页面脚本或侧栏。

## 失败与恢复

发起网络请求前先保留一份待保存材料，将正文、来源和目标服务绑定。未发送草稿可以改名或显式丢弃。一旦开始发送，结果不确定时会冻结请求，重试使用同一采集身份与正文。服务恢复不会自动上传待保存材料。更改服务也不会迁移既有采集。收到服务端成功回执后才能打开条目；最多保留 64 条回执链接，使先前页面按钮仍可使用，不建立第二套内容库。

更新已解压安装时，在 Chrome 扩展管理页重新加载扩展，再刷新来源网页以载入新页面脚本。请查看 Chrome 显示的新权限。本扩展不需要构建；DSH Host 桥或 Web 应用变更需要仓库常规构建。相对于先前已构建的桥，本轮只修改扩展。

## 开发验证

在仓库根目录运行：

```powershell
pnpm exec vitest run apps/chrome-extension/tests --config vitest.config.ts
```

聚焦测试覆盖安全阅读预览、状态转换、目标变更、worker 重启后重试、来源限制、令牌轮询、选区提取和动态页面按钮。构建后浏览器验收位于 [content-extension.e2e.ts](../web/tests/content-extension.e2e.ts)。原采集流程的真实页面验收不能证明新增网站按钮的兼容性：ChatGPT 和知乎可能改变 DOM，适配器仍需重新在真实页面检查。远程 HTTPS 部署和原生权限提示属于独立验收条件。
