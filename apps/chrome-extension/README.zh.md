# DSH 浏览器助手

[English](README.md) | 中文

这是 Manifest V3 的 DSH 浏览器助手，要求 Chrome 116 或更高版本；版本在 [manifest.json](manifest.json) 中声明。它以会话侧栏替换原收藏控制器入口。加载解压版前运行 `pnpm run build:chrome-extension`；根构建依赖固定 `puppeteer-core` 24.31.0 和 `esbuild` 0.28.1，并生成 `vendor/puppeteer.js`。

## 使用侧栏

连接恢复依靠浏览器生命周期事件，不进行无限轮询。短暂断线最多进行五次不带凭据的 HTTP 探测，依次退避 1、2、4、8、16 秒；仅在服务响应后尝试 WebSocket。之后连接暂停。浏览器启动、扩展更新、已配置服务的顶层页面成功加载、侧栏重新显示，或侧栏收到网络上线事件时，可使用已保存凭据进行一次恢复尝试。并发事件合并，持久化的十秒冷却防止事件风暴和 worker 重启反复探测。连接稳定后恢复短期重试预算。主动断开和凭据撤销不会自动重连。若服务只在后台恢复且没有浏览器事件，则等待下一个事件或“重试连接”，不使用后台轮询兜底。恢复不会重放页面输入，也不会重新配对。

浏览器动作可返回有界转移观察：来源页面、同一标签中重新验证的页面，以及最多八个候选子标签。子页关系不能证明由哪次输入打开，也不会自动选择子页。取消或请求截止会停止观察；动作结束后的额外观察窗口最多为 250 毫秒，不覆盖更晚的事件。两种显式开页方式均创建后台标签，并返回完整的浏览器会话标签引用。

同一个扩展可以独立连接 Codex 和 DSH。安装监听 `http://127.0.0.1:3091` 的独立浏览器连接器后，在“连接与设置”点击“连接 Codex”，再从 Codex 提问或操作目标网页，无需运行 DSH。两条连接分别管理凭据、结果和断线，共用浏览器执行账本，避免未确认结束的写入在同一标签上冲突。扩展内的聊天和阅读控件继续使用 DSH。

解读页未连接时直接显示连接卡片，可填写 DSH 地址并使用现有连接流程。首次配置、等待连接和临时离线分别显示对应提示。连接前隐藏空的阅读控件，已有解读仍可查看；临时断线使用已保存的授权重连。

“解读”页独立选择模型与支持的推理强度，列表来自 DSH 已配置的全部服务商，包括兼容接口的自定义模型。“DSH 完整设置 ↗”通过 `/#settings=models` 打开完整设置面板，可配置服务商、API 地址、密钥、模型列表及其他 DSH 设置。密钥保留在 DSH，扩展只保存解读模型选择；配置后可刷新模型列表。

扩展侧栏内部提供“对话”和“解读”页签。“解读”使用侧栏主区域显示 AI 回复，隐藏输入区、采集按钮和授权提示，支持调整字号、切换近期解读及实时更新；“对话”恢复原聊天界面。切换页签不会创建浏览器标签页，也不会离开知乎。

知乎推荐流的问答卡片和专栏文章卡片在底部操作栏最右侧提供“AI 总结解读”。点击后打开原侧栏并直接切到内部“解读”页签，在当前知乎页面展开并读取该条回答，通过 DSH 模型适配器发送一次独立请求，不创建会话，不包含聊天历史或工具定义。最近 30 条解读保存在扩展中，仅供查看，不会作为后续上下文发送。解读自动显示最新生成内容，不跳转页面。追加加载的卡片也会显示入口。发送后链接变为“已发送 · 查看解读”，再次点击只显示解读，不重复提交。未完全展开、达到文字上限或包含未采集的图片时，分析请求会说明材料范围。更新扩展后刷新知乎页面使入口生效。

从工具栏打开侧栏，或使用 Chrome 的 `Alt+Shift+A` 命令。连接后首次发送会按 DSH 默认 Agent 预设自动创建 Session，也可以选择已有 Session。不能发送时，输入区会说明原因并保留草稿。在 HTTP(S) 页面中选中文字并使用“用 DSH 讨论选中文字”加入草稿。“正文”采集已加载的网页正文；侧栏在用户发送前预览正文、选区和真实 Chrome 截图。它也可以停止或恢复所选 Session，并在 Web 应用中打开同一个 Session。

在 ChatGPT 回复、知乎回答和知乎专栏页面中，页面操作栏还会显示“采集到 DSH 内容库”。点击后由扩展校验当前页面身份，将用户明确选择的内容发送到 Content，并在页面按钮和侧栏“当前采集”区显示导入状态。成功后可以打开 DSH 内容；失败、断线或结果未知时只允许处理原请求，不会静默重复提交。扩展只保存采集绑定与回执，内容持久化和后续业务整理由 DSH 负责。

内容库导入授权与助手会话授权分别显示；侧栏会明确显示“内容库已连接”或“内容库尚未连接”，不会把助手已连接误认为内容已落库。

正文采集优先读取页面主区域或文章，保留 URL、标题、文档身份和采集时间。编辑区、隐藏内容、导航、评论和操作控件不会进入正文。折叠或仍在生成的部分会跳过并提示不完整，扩展不会自动展开它们。正文最多采集 48,000 字符或遍历 10,000 节点，达到上限会标明截断。目标文档被替换，或采集完成时前台标签已经改变，会拒绝结果。草稿最多保留三项上下文，合计不超过 5 MiB。

默认 DSH 地址为 `http://127.0.0.1:3080`。个人部署连接一次即申请所有 HTTP(S) 网站的读取、操作和观察权限，同时启用会话交互。服务地址和安装授权持久保存，直到撤销，无需逐站点或逐次操作确认。已有局部授权可点击“永久授权所有网站”升级一次。仅在使用其他端口或服务器时修改地址。地址必须是 HTTP(S) origin 根路径，不支持部署路径前缀。

manifest 请求所有 HTTP(S) 网站访问权限、`activeTab`、`debugger`、`webNavigation`、侧栏支持和选区右键菜单。更新后须重新加载解压版扩展，使 Chrome 应用 `debugger` 和 `webNavigation` 权限；浏览器内部页面仍受 Chrome 自身限制。截图采集仍使用 Chrome 的 `activeTab` 能力。Chrome 运行时，`Ctrl+Shift+7` 全局快捷键可打开或聚焦独立助手窗口，即使当前焦点在其他应用中。设置按钮打开同一窗口，并与侧栏绑定同一个 Session；可在 Chrome 快捷键设置中改键。扩展不会自动提交页面内容；采集按钮只在受支持页面注册，并由用户明确点击后发送。令牌和 verifier 保留在扩展受信任存储中，绝不进入页面脚本。

## 网页操作引擎

扩展打包 Puppeteer 浏览器侧公开实验性 `ExtensionTransport`，并通过 `chrome.debugger` 连接当前已登录的 Chrome 标签页。传输方式参考 [Nanobrowser](https://github.com/nanobrowser/nanobrowser)，但不引入它的 Agent 循环、模型接入或界面。Puppeteer 是默认引擎，执行全部已实现动作：`click`、`fill`、`submit`、`double_click`、`right_click`、`hover`、`press`、`select`、`check`、`drag`、`upload`、`navigate`、`back`、`forward`、`reload`、`tab_open`、`tab_close`、`tab_focus`、`scroll`、`wait` 和 `screenshot`。DOM 兼容模式只保留早期的 `click`、`fill`、`submit`、`navigate`、`scroll` 和 `wait`；新动作请求会明确失败。首个鼠标或按键 press 发出后，停止会允许对应的 release 完成、报告 `unknown`，绝不承诺撤销在途操作。

快照包含每个控件的标签、角色、可视区状态及附近卡片或区块标题。`tree` 快照从一份稳定缓存分页返回完整的 Document、元素、文本和开放 Shadow Root 层次；每个节点保留稳定的 index 和 parent index，返回的 cursor 读取下一页而不重新匹配节点。iframe 元素标出 source 边界，iframe 文档仍通过独立 frame 读取。树会排除隐藏、可编辑、script 和 style 文本，并保留隐藏结构而不暴露其标签或文本。受信任的任务快照还会把有界 mount／文本展示查询经执行器传给隔离页面运行时；每项回答都绑定精确 Session、installation、grant epoch、页面和仍连接的真实面板实例，不会匹配页面任意位置的同文或伪造 mount 属性。[浏览器工具](../../packages/browser/tool-browser/README.zh.md)负责模型可见的预算与操作后的新反馈。截图仅支持主 frame，base64 上限为 400,000 字符；后台目标会使用不切换焦点的 Puppeteer 路径，否则明确失败，不会激活用户标签页。上传最多接受 16 个绝对路径，且当前用户消息必须逐一写出准确路径；工具会在执行前检查该来源，不额外显示批准框。

带 `query` 的控件快照将正文与结构限定在本次返回控件的局部容器，`textScope` 区分局部证据和整页正文。独立 [MCP 连接器](../../packages/mcp/browser-extension-mcp/README.zh.md)可明确请求当前 input/textarea 值用于提交前核对。默认读取和后台观察省略这些值。密码、文件、隐藏输入框和 autocomplete 标明的凭据或支付信息仍然排除；截断值不能证明完整匹配。

点击在驱动完成滚动、稳定性与命中检查后，使用该精确控件的可点击位置。鼠标输入保留逐包权限检查，不再重复等待可能在后台标签页中暂停回调的视口观察器。

已完成的点击或按键若在反馈读取前替换了文档，回执只确认输入已完成，并标明反馈不可用。转移观察提供替换后的页面身份，供重新读取。输入中断、授权撤销和填写结果无法核实时仍保持未知；执行器不会推断业务成功或重放输入。

标签列表为每个已授权标签提供完整的 `tabId`、`windowId` 和 `browserSessionId` 引用。带 `expectedTab` 的快照在采集前后核对身份，并返回已核验的 `tab`；标签移动或引用失效会失败，不会改选其他页面。任务范围与子页选择仍由调用方负责。

## 后台监控

连接后打开“监控”，无需另行授权站点。计划归属于当前选择的会话和界面显示的网页地址。可以选择一次检查或周期检查、正文变化或文字匹配条件，以及补查最近一次或跳过错过周期。侧栏与 Web 关闭后，Host 仍会保存计划，并通过 Queue 执行每次有限检查。

工具栏角标显示 Host 待确认通知数量。worker 在连接时和每 15 秒刷新，侧栏按持久通知 ID 显示，点击“已读”后才确认移除。打开所属会话使用原监控的归属，不受当前前台网页影响。暂停会停止后续检查；恢复会明确绑定当前观察权限。创建回执丢失时，原请求 ID、会话和网页地址跨 worker 重启保留，可用“重试原请求”确认。Chrome 不另建任务或通知数据库。

## 浏览活动

授予观察权限后打开“活动”，选择站点、事件种类、采样间隔、正文和保留边界，再显式保存到当前会话。采集器只观察获得焦点的普通浏览器窗口，并在采集前后检查 Chrome 持续站点权限。临时 `activeTab` 访问不能单独启用它。正文默认零字符；连续活动不采集图片。页面观察器仅保留变化标记，不续租即到期停止。

“暂停采集”会先停止本地采集，再等待 Host。确认后的暂停跨 Chrome 与 Host 重启保留；“保存并开始（当前会话）”显式恢复。当前连接的策略尚未同步时不可配置。已知版本冲突会解除被拒绝的请求，但持久保持本地暂停，直到再次显式保存；结果未知时保留原请求身份用于确认。

Chrome 最多缓冲 32 条内存事件和一个最多 32 条事件的持久批次，并受编码字节边界限制。溢出和策略失效记入丢弃数量。最近批次重试保留原 ID 和序号，不会新增重复的 Host 事件。“检索 DSH 活动”在当前站点与授权范围内搜索 Host 持有的历史。原始活动与[监控摘要](../../packages/browser/browser-monitor/README.zh.md)及整理知识分开存储。

## 思源知识衔接

部署使用本机思源原生 MCP 时，在所选 `dsh web` Profile 中显式加载[可选连接补丁](dsh-siyuan.cordis.patch.yml)。它复用现有 MCP 客户端，以 `serverName: siyuan` 连接 `http://127.0.0.1:6806/mcp`。如果部署已有该命名空间，应复用原连接，不再加载另一个实例。补丁不启动思源，也不配置笔记本。共享的 `siyuan-knowledge` Skill 提供用户的库位映射与写入约定。

在“活动”中输入过滤条件，选择“提炼知识”或“整理资料”，再点“整理并保存到思源”，即可向同一会话提交明确保存请求。Agent 检索该会话的历史活动，区分观察事实与解释，核对已有笔记，再写入相关摘要并通过原生 MCP 回读与检索验证。稳定来源标记有助于避免重复；连接不可用时不能声称写入完成。MCP 连接决定可用工具；目标库与非破坏性写入仍是 Agent 工作流约定，不是新增的逐动作访问控制系统。

## 恢复与历史

Chrome 在离线或重启期间保留不可变 pending submission 或 `pendingCreate` 绑定。创建重试会保留固定 Session id；已提交请求保留调用方生成的 id，并在回执丢失时变为 `unknown`。重新连接只恢复状态和 follow cursor，不重放输入。完整消息历史由 Host Session 拥有；Chrome 只保存其绑定和 pending 状态，内存最多保留 1,000 条 record 或 2 MiB，并会在请求时打开同一个 Web Session hash。

更新已解压安装时，请在 Chrome 扩展管理页重新加载扩展。查看 Chrome 显示的权限后，在标签页中打开工具栏再采集截图。旧内容库记录和已存数据会保留，当前页面采集按钮与侧栏当前采集区继续使用同一份回执。

## 连接行为

独立 Codex 连接可在 relay 重启后续授权，无需重载扩展。[恢复协议](../../packages/mcp/browser-extension-mcp/README.zh.md#connection-recovery)区分凭据失效、撤销、不受信任扩展与网络故障。主动断开或收到终止授权拒绝后，自动恢复停止，worker 重启也不会解除该状态。重连绝不重放未知浏览器写入。

保留中的执行回执占满日志时，`journal_capacity` 拒绝会携带 `value.admission.executed: false` 和 `recheckAt`。该时间戳是已停稳写回执最早过期的 Unix 毫秒时刻，只提示何时重查，不预留容量；`null` 不承诺按时间恢复。到期后，新的可准入读取可在同一安装中继续。仍可能执行的请求不因时间流逝而失去保护，未知结果也不授权重复输入。

worker 为所选 Session 流式传送首个 snapshot 和后续按 cursor 寻址的 events。可见且同 Session、具备 `session:interact` 的 peer 能通过既有 Approval answer chain 接收浏览器操作卡；隐藏或断线 peer 委托 Web，取消或超时会移除卡。对于未知操作，journal 直接持久化最小 identity、outcome 和完全停稳事实，无需人工确认：只有仍可能运行的操作占用标签页，已证明停稳的结果会释放占用并保持可查询，后续连接仍可同步它。真实登录站点与真实模型的验收取决于部署配置。扩展不管理 Chrome 用户配置，也不替代 DSH Web 应用的会话历史。
