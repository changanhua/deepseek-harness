# 浏览器助手语义页面地图计划

[English](2026-09-21-browser-assistant-semantic-page-atlas.md) | 中文

主视图和交付路线由已批准的[语义导航计划](2026-09-21-browser-semantic-navigation.zh.md)替代。下文区域布局设计保留为历史方案，不再作为语义地图的完成标准。

**目标 / 完成条件：** 将按观察记录排列的页面认知卡改为每个精确页面文档一张有证据的语义地图。用户可以一眼理解页面结构、已知内容、可用操作和重要遗漏，选择区域查看详情，并定位当前引用；不能把推测或未读内容称为已知。

**范围：** 本计划负责认知投影和扩展渲染，不新增阅读器、存储系统、网站专用抓取器、授权路径、后台轮询或模型生成的事实来源。[个人浏览器助手 V2 决策](../../../.agents/notes/proposed/feature/2026-09-20-personal-browser-assistant-v2.zh.md) 负责设计理由和权限边界。

## 设计理念

### 一张地图，三种阅读速度

主视图是语义地图，不是截图，也不是工具观察记录列表。不到一秒可通过形状和状态识别主要内容、侧栏与未读区域；几秒内可从区域卡查看已送达内容、集合项和操作；选择区域后通过检查器查看已知内容、可用操作、遗漏及证据。实体提取留到后续实体分组阶段。

页面地图合并概览和操作发现。新增“结构”和“证据”作为次级检查视图：“结构”展示已送达 DOM 树及其范围限制；“证据”展示观察来源、时间、精确页面身份和遗漏。这两个次级视图回答调试、核验问题，而不是日常的“Agent 知道什么、在这里能做什么”。

### 证据先于视觉效果

每项可见事实都来自已提交并送达 Agent 的结果。实线、部分和未读状态表达已观察范围，不表达视觉置信度。无法确认的几何位置或区域归属保持未放置，不能编造。仅当精确页面、快照和元素身份仍有效时才显示定位入口。

地图可缩短已送达文本用于展示，但不能创建权威的模型摘要。未来的生成式综合必须标明由模型生成、引用证据记录，并与确定性事实在视觉上区分。

### 通用内核，随页面变化的表达

一个页面模型支持文章、问答流、目录、搜索结果、表单、仪表盘及未知页面。展示器可根据语义角色、标题、集合和控件选择符合页面的名称与重点，但不能改变证据、覆盖度、定位有效性、操作权限或遗漏。

只有实际网页证明通用语义无法恢复重要且重复的结构时，才引入网站专用适配器。适配器只增强名称和分组，保留通用回退，且不得自行读取或操作。

侧栏保持适配器角色。Browser provider 在 DSH 权限下采集有界证据，Host/Session 日志拥有已提交事实，`assistant-cognition.js` 只做纯确定性投影，侧栏负责渲染和分发类型化命令。扩展 UI 不持久化独立语义状态，也不决定生命周期或授权策略。

### 保留空间事实，不仿制像素

地图把已观察区域边界归一化到稳定网格，保留顶部、主体、侧栏、重复信息流和视口下方等大体关系，不复制网页样式或每个嵌套 DOM 框。嵌套地标默认合并到最近的有用父区域，除非其内容、操作或覆盖度明显不同。

当前页面默认展开。其他当前文档显示为紧凑地图卡；先前文档保留证据摘要，但定位引用无效。观察记录数量不能作为页面数量。

### 显示操作不等于授予执行权限

区域操作按钮用于发现和精确页面定位。修改性操作继续遵守现有 Browser 动作、批准、目标修订及未知结果规则。页面地图不能授予权限、重放不确定写入或静默切换到前台标签。

## 冻结的投影约定

投影在一个 Session 内按 `installationId + tabId + frameId + documentId + url` 对观察记录分组。每个页面公开身份、当前/先前状态、观察记录、聚合覆盖度、区域、未放置操作、遗漏和证据引用。每个标签/框架的最新文档为当前文档，更早的精确文档为先前文档。标题来自已送达快照标题，缺失时使用精确 URL。页面类型来自已送达的明确语义角色或集合，缺失时为未知；搜索结果使用目录/列表表达。框架身份保持可见。有界事件窗口可能丢失早期证据，投影应说明此限制，不另建历史存储。

每个区域公开投影 ID、语义角色、名称、归一化边界、重要度、覆盖状态、有界的已送达文本、集合摘要、当前操作、遗漏和证据引用。边界与语义内容来自 `browser_page_map` 和已送达快照；投影移除 selector 等私有实现细节。在同一页面内，以唯一的角色/名称组合跨观察匹配；无名称的区域要求唯一且完全相同的角色/文本组合。保留首次匹配的观察身份，不使用变化的边界或文本哈希充当稳定身份。歧义匹配保留为独立证据。最新区域观察决定展示的区域清单，旧清单留在“证据”，不增加当前区域数。几何归一化只在一次观察内进行，不将不同时刻的视口坐标当作同一坐标系比较。

每个操作保留精确页面、快照和元素身份、角色、名称、状态及区域归属。只有同一次观察的可信边界或唯一明确的语义关联能确定归属。无法可靠归属的操作进入未放置操作；渲染器不能猜测区域。区域只有具有属于它的有效已送达元素引用时才提供定位，否则选择操作只打开检查器。定位资格要求引用属于该精确文档最新观察快照且未超过提供方保留期限；提供方在分发时再次检查缓存淘汰和文档身份。过期引用保留为历史，失败提示手动刷新，不自动重新读取。

覆盖度是一组明确指标，不是虚构的完整度分数：已送达文本量、已观察集合项与可信报告总数、返回控件与分页状态、树节点/游标、已观察区域及已知截断。控件 offset 不是文本 offset。纳入已送达 `browser_extract` 集合项和控件引用，但其筛选后的有界项数不代表页面总数。集合计数达到提供方的 128 钳制值时，分母视为未知。页面地图区域达到 32 个或结构摘要区域达到 24 个时，提示可能截断。只有明确可信的总数才能形成局部比例，缺失总数保持未知。

投影继续遵守现有 Browser 上限。每次观察最多保留已送达的 32 个区域、128 个控件及有界树/文本预览；通过聚合引用工作，不存储第二份完整 DOM 数据库。

## 交互与布局规则

- 页面地图是默认认知视图。只保留“结构”和“证据”两个次级标签，不能恢复独立的“概览”或“可操作”标签。
- 读取状态除颜色外还使用文字和边框表达。每个页面卡和地图区域均可通过键盘选择，并具有等价的无障碍名称与状态；遍历顺序遵循渲染顺序。
- 按送达顺序在区域内直接显示第一个有效定位引用。检查器列出全部操作，并作为其余操作计数的访问入口。这些控件只定位元素，不执行元素对应的网站操作。
- 选择区域后只更新一个检查器，其中包含“掌握内容”“可用操作”“尚未覆盖”。初始显示选择引导。窄布局用邻近状态和无障碍实时通知使选择结果可感知；滚动不得抢走键盘焦点。检查器不重复原始 DOM 元数据。
- 在固定页面中定位区域或元素，不改变目标。陈旧定位仅可作为历史证据显示，不能分发操作。
- 容器宽度是唯一断点：至少 700 CSS 像素时地图与检查器并排，更窄时上下排列。长段正文每行不超过约 72 个字符。
- 页面组成卡片组：保留用户当前选择；初次优先展开精确固定目标页，否则展开最近观察的当前页面。其他页面显示包含标题、页面类型、覆盖度和遗漏的紧凑语义缩略图。键盘选择更新同一个展开页面，不改变任务目标。
- 请求刷新时保留已提交事实，并显示正在提交、等待已送达观察或本次结束但没有新证据。重复点击不能重复排队；失败通过现有请求核对流程重试。
- 缺少边界、页面类型未知、Canvas、跨域框架及虚拟列表必须有确定性通用回退；回退是语义大纲，不能是空地图。

## 交付计划

### P0 — 以失败测试冻结页面级行为

所有者：主集成者。先扩展 `apps/chrome-extension/tests/assistant-cognition.spec.ts`，再修改生产代码。RED 用例覆盖：多次观察合并为一个精确页面、页面数与观察数区分、当前/先前文档、区域边界/文本保留、明确遗漏、未放置操作、动态 DOM 匹配及陈旧或被淘汰的定位引用。保留父计划 I4 覆盖：实际送达前未读、部分覆盖不夸大、Session/文档隔离、点赞不增加读取及刷新仅走一条请求链。命令测试数据冻结页面/观察/操作身份和预期 Session/目标修订。

完成：每个测试都能指出使其通过的生产改动；失败来自当前观察列表投影，而不是测试数据或导入错误。

### P1 — 投影页面、区域和覆盖度

所有者：主集成者。把 `apps/chrome-extension/src/assistant-cognition.js` 从 `{ items }` 改为页面级投影。保留公开 `browser_page_map` 的 role、label、text、importance、stability 和 bounds；确定性归一化几何位置，仅在身份和内容等价可证明时去重嵌套地标。每个页面内部继续保留观察来源和历史。同时更新 `assistant-runtime.js` 消息处理和 `assistant-view.js` 状态传递，包括刷新状态与精确引用定位。纳入 `browser_extract` 证据，不编造区域归属或页面总数。

只有测试证明语义上下文无法可靠分配操作时，才给 `apps/chrome-extension/src/browser-page.js` 增加元素边界。任何新公开字段都通过现有 Browser 结果链路限制并验证；不增加 Host 路由或持久化格式。

完成：`pnpm run test -- apps/chrome-extension/tests/assistant-cognition.spec.ts apps/chrome-extension/tests/browser-page.spec.ts apps/chrome-extension/tests/browser-dom-tree.spec.ts apps/chrome-extension/tests/browser-context.spec.ts apps/chrome-extension/tests/assistant-runtime-functions.spec.ts apps/chrome-extension/tests/sidebar.spec.ts` 覆盖父计划 I4 承诺及命令接收端。畸形或极端边界关闭失败；投影期间不读取页面。P1、P2 作为一个候选集成后再构建或重载，不要求临时双投影。

同一扩展运行时中的目标绑定、清除和定位共用一条串行通道，并在执行后复核 Host 修订。另一 Host 客户端仍可能在本地高亮执行期间改变目标；彻底消除该分布式竞态需要新增 Host 预约/分发路由，因此不属于本实施切片，也不能在本期声称已原子证明。

### P2 — 将页面地图渲染为认知主界面

所有者：P1 冻结测试数据后由 UI 实现代理负责。仅按需修改 `apps/chrome-extension/src/sidebar.js`、`sidebar.css`、`sidebar.html` 和 `tests/sidebar.spec.ts`。渲染页面卡片组、地图网格、区域定位按钮和选择检查器；新增指定的“结构”和“证据”次级视图。使用容器查询实现宽屏与上下排列布局。对话内读取回执继续从页面内的观察派生，页面计数与观察计数独立。

完成：sidebar 测试覆盖页面与区域键盘选择、选择通知、刷新反馈、“结构”/“证据”内容、检查器完整操作访问、宽屏/上下布局钩子、当前与先前页面、空白/回退地图、陈旧定位及命令参数。保留全部非认知回归。渲染器只消费投影事实，不包含网站识别或 Host 策略。

### P3 — 证明跨网页通用性

所有者：Sol 集成。为文章、问答流、目录/列表、表单/仪表盘及未知页面增加确定性测试数据。测试一条通用投影和展示链路，不能创建五个网站适配器。验证每类网页都显示主要区域、主要集合或字段、安全直接操作及明确缺口。

完成：相同投影和渲染器通过全部测试数据。只有一个重复语义模式无法在不损失重要内容或操作分组的情况下表达时，才增加专用展示器。

### P4 — 真实扩展边界与验收

所有者：Sol。构建扩展、重新加载准确候选版本，检查一个真实知乎问题页和一个结构明显不同的页面。对照观察区域验证地图几何，对照已送达结果验证内容/操作，对照真实截断验证未读区域，并在固定页面验证每个定位入口。浏览另一标签不得重定向地图或其中操作。

完成：若不存在则创建 `.artifacts/browser-assistant-v2/semantic-atlas/`，保存截图、会话/请求/页面/快照身份及来源结果对照。包含无关点赞数变化后读取计数不变、一次显式刷新链和过期引用拒绝场景。第二个页面选文章或结构化列表并说明观察范围。HTML 原型只是视觉参考，不是验收证据。在源码和专项检查稳定且准备进行真实边界运行前，不重启正在工作的 Host。

## 演进方针

只有一项新事实能改善至少三种页面模式的一眼理解时，才放入地图。区域细节进入检查器，原始生命周期和 DOM 事实进入“证据”或“结构”。仅当某个用户任务无法由地图、检查器或证据表达时才增加新的认知一级视图。

优先使用通用语义角色和集合模式，不优先使用领域名称。增加适配器前保留可用的通用回退；通用模型达到相同清晰度后删除适配器。

以四项结果评估改进：识别页面主要内容所需时间、已知与未读边界的正确性、找到目标操作所需时间，以及没有错页或陈旧定位分发。视觉密度本身不代表成功。

后续层按顺序推进：更好的确定性实体分组、多页面对比、可选截图底图、可选生成式综合。每层均需独立证据，且不能削弱确定性事实、目标权限、有界读取或无障碍能力。

## 扩大条件

如果实现需要自动页面轮询、第二份 DOM 存储、权威投影中的模型生成事实、向侧栏暴露 selector、具有独立读写能力的网站适配器，或比有界几何/语义分组更宽的 Host/公开 Browser 约定，则停止并修订设计。

目标、权限、持久化或未知结果规则变化时，实施前升级给 V2 所有者。普通 CSS/布局迭代和确定性投影修复留在本计划内。
