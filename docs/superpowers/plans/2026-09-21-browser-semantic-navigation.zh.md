# 浏览器语义导航交付计划

[English](2026-09-21-browser-semantic-navigation.md) | 中文

## 已批准的结果

用户从浏览器助手进入已采集页面的主题概览，聚焦主题后看到下一级内容与来源，点击来源能定位并高亮正确原文，再返回原来的阅读位置。模型概括、网页原文和人工判断分别标识。文章、教程和文档是首条完整路径；FUTBIN 保留为列表类验收目标，不能以仅支持文章宣告本次任务完成。

## 所有权与复用

`SourceSnapshot` 复用 Browser 采集与 Session 的已提交工具结果，记录精确文档、快照、提取器版本、有序内容块和缺口。浏览器私有缓存只保留回源所需的节点与原文核对信息，不授予写操作能力。`SemanticMap` 是绑定来源结果的可替换派生产物，通过普通工具结果持久化。`ViewState` 保存地图版本下的展开路径、选择和位置；模型不修改它。

模型通过 `browser_publish_semantic_map` 提议分组、命名与概括，只能引用已有块编号。发布工具从发起会话读取已送达快照，校验引用、层级、总量与版本。程序分配地图及节点身份，未被组织的原文仍可访问。新候选不自动合并旧身份，地图版本内的布局和展开是确定性的。

扩展在语义生成的用户回合加入标记，可重放的 Session 投影在 Host 恢复后保留该状态。Host 的单调工具守卫在该回合结束前只允许 `browser_snapshot`、`browser_read_source` 和 `browser_publish_semantic_map`，模型尝试 Dynamic Cordis 或工具转发也受限。标记只收紧权限，不授予权限。须用网页注入指令验证该边界，并确认后续普通回合恢复原有工具策略。

## 依赖顺序

1. 来源闭环：有界正文块、代码和表格原样表示、同文不同块、段落回源及文字变化拒绝。缺失原文、缓存淘汰和文档更换必须明确失败。
2. 语义候选：最小两级导航格式、来源校验、未知引用与过期结果拒绝、未组织内容保留。模型只解释，不自行制造来源或定位信息。
3. 完整阅读路径：显式生成，Overview → Focus → Source，展开不调用模型，返回保留位置。没有合法语义产物时显示原文结构导航及生成状态，不称其为语义地图。
4. 阅读反馈：在受信扩展存储中独立保留人工修正与错误标记，绑定精确地图及节点。串行保存、拒绝冲突修订，新候选不覆盖修正，并记录有界的回源成败，不改写来源证据。
5. 真实验收：真实模型生成、扩展到原网页的回源断言、留出样本和阅读任务比较。截图、合法 JSON、构建和结构测试均不能单独完成验收。

## 并行所有权

主集成者拥有来源契约、扩展采集、投影、界面、运行时、文档和最终验收。工具实现代理仅拥有发布工具及其单元测试。只读探索负责当前 Session/工具契约，独立审查在候选稳定后检查引用、版本、权限和证据缺口。共享契约、目录生成及集成串行。

工具集成后，验收代理拥有真实浏览器语义测试及固定评测样本。独立的反馈实现代理只拥有本地反馈存储及其单元测试；主集成者拥有受信消息准入和全部界面集成。两个实现代理均不修改生成提示词、公共来源契约或对方文件。

## 验收条件

来源测试覆盖重复段落、代码空白、表格顺序、截断、删除、改文和换页。发布测试覆盖不存在的引用、伪造工具文本、跨会话、过期快照、生成时重绑或清除目标、后续不确定快照、循环、孤立节点和总体大小。浏览器测试必须断言实际高亮原文与预期片段一致，并检查键盘、窄布局、返回位置和失败降级。

语义评测检查对象、数字、否定、限定条件及不同作者归属。辅助模型复核只标记疑点，不宣称正确性。约 20 个固定页面样本中保留留出集；逐步加入文章之外的页面，至少单独记录 FUTBIN 的结果。以找到正确原文、耗时、展开次数和误解对照原生目录、搜索和普通摘要，任何收益百分比必须来自实测。

## 边界

不自动读取未采集页面，不以 DOM 变化触发模型重跑，不画无依据的关系线，不将模型评分标为可信度。首版不承诺理解无限滚动页面的全部内容或复杂因果。旧快照可读与当前页面可定位分开判断；失效时保留原文证据，不猜测新位置。

本计划替代[区域地图计划](2026-09-21-browser-assistant-semantic-page-atlas.zh.md)的主视图和交付路线；其精确页面、授权和未知结果约束继续适用。完成条件是受支持页面上的完整导航和回源证据，而不是任意一项前置能力通过测试。
