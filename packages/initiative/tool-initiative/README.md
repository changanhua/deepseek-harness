# @changanhua/dsh-tool-initiative

English | [中文](README.zh.md)

## Summary

Scoped Agent Candidate proposal, investigation and query tools.

## Use this package

initiative_record permits propose and investigate only. initiative_read selects exact versions or bounded pages. The Tool registry supplies exec.agent; JSON cannot impersonate Human authority. Provider checks still reject direct Agent settlement or promotion. maxOutputBytes bounds complete output and timeoutMs participates in the existing cooperative tool-timeout policy.

See [setup and commands](../README.md) and the [Initiative subsystem](../../../docs/subsystems/initiative.md).

## Invariant policy

No invariant companion is published because the Tool and prompt registries own reversible registrations.

## Model Experience

### Candidate guidance and tools

#### What the model sees

`initiative_record` and `initiative_read` schemas and stable proactive-intake guidance. Candidate content remains untrusted reference data.

#### Token effect

Guidance, schemas and bounded results add tokens only when composed.

#### KV Cache effect

Guidance and schemas remain prefix-stable while this plugin is unchanged.

## Known Limitations and Deferred Work

- No cold trigger or unattended investigation is installed. Tools do not fetch sources or score RIR. Keep maxOutputBytes above the provider maxCandidateViewBytes plus the response envelope. Use smaller pages for large lists.
