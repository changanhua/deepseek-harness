# @changanhua/dsh-image-generation

English | [中文](README.zh.md)

Shared Service Definition for `ctx.imageGeneration`. Providers register a stable id; consumers first call `resolve()` to persist provider facts, then call `generate()` with the resolved spec and prompt.

## Extension points

`registerProvider()` ties provider registration to the contributing Cordis fiber. Automatic selection succeeds only when exactly one provider is registered; otherwise callers select a provider explicitly.

## Model Experience

Indirectly, through image-generation consumers that own model tools and result rendering.

#### KV Cache effect

No direct invalidation; consumers own every model-visible schema and result.

## Known Limitations and Deferred Work

- The service coordinates providers but does not persist requests or generated bytes.
- Provider selection has no priority or fallback chain.
