# Case Studies

这里存放真实 DSH 设计的重构训练，不存“标准答案速查表”。

## Reveal rule

进入一个 case 时，先只给 Problem / Constraints。学习者必须先产生 independent reconstruction evidence，之后才能阅读旧实现并做 review。

## Planned cases

- `runtime-awareness.md`：authority、freshness、projection、prompt budget、pull introspection。
- `task-queue.md`：durable truth、consumer、claim、lease、attempt、restart、recovery。
- `observability-orchestration.md`：时间语义、事件、幂等、并发与可观测性。

这些历史实现只提供训练材料，不自动代表当前最佳实践或 DSH contract。
