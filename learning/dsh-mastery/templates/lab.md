# Lab — <title>

## Capability Target

本 Lab 对应 `CURRICULUM.yaml` 中哪些 capability。

## Problem

给出真实、可验证的问题，不先暴露解决方案。

## Prediction Before Action

在读完整实现或运行验证前，学习者先写出：

- 预期调用/状态路径；
- 预期 state owner；
- 可能失败点；
- 预期验证结果。

## Source / Runtime Scope

固定目标 repository、commit、profile、入口或复现实例。

## Tasks

1. 找最小源码路径。
2. 做实验或最小修改。
3. 运行验证。
4. 比较 prediction 与 actual。

## Verification

明确命令、测试、trace、日志或运行结果。能机器检查的不要只做自然语言自评。

## Reflection

- 哪个预测正确？
- 哪个预测错误？
- 错误来自什么心智模型？
- 下次遇到类似问题应该先检查什么？

## Evidence Required

生成一条 `evidence/` 记录，保留 prediction、事实、verification 和 routing implication。

## Exit Criteria

通过标准必须可观察，并测试对新例子的迁移能力。
