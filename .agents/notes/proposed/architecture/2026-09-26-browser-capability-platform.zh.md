# Agent Note: 浏览器能力平台设计基线

Status: proposed

[English](2026-09-26-browser-capability-platform.md) | 中文

## 问题

一次成功的浏览器演示不能确定平台职责。围绕单个选定文档的设计，可能漏掉首次开页、链接进入新标签、同文档路由变化，以及操作回执丢失后的恢复。只实现演示流程，会让这些缺口逐渐变成互不相干的例外，并让 DSH 与 Codex 重复实现执行逻辑。

用户希望扩展不频繁变化、复杂度合理，并保留两个 agent（智能体）环境的能力。用户要求从已有页面或新 URL 开始处理复杂浏览场景，要求设计兼顾 Cordis，并将当前交付限定为浏览器能力。这些是用户要求；下文机制属于设计建议，不是此前已批准的要求。

## 提案

### 最终用户结果

用户把浏览器任务交给 Codex 或 DSH agent。agent 可以从明确选定的页面开始、发现已授权的现有页面，或者不依赖旧页面引用直接打开 URL。它观察页面，操作新鲜目标，跟随允许的转移，并用独立页面观察支持结果报告。用户能够检查当前目标和未决动作。Codex 使用独立浏览器连接时，DSH 可以离线。

本文是供评审的设计候选 browser-platform-r1。它明确预期行为和首期边界，不代表已经实现或通过运行验收。只有这份产品边界被接受后，才确定实现切片。一条成功演示不能替代下文场景矩阵。

### 要求对应

| 用户要求 | 设计建议 | 能够否定设计的证据 |
| --- | --- | --- |
| 扩展尽量少因业务变化更新 | 浏览器机制留在扩展；网站知识和计算留在 agent 环境 | 第二个网站要求执行器增加领域专用分支 |
| 保留 DSH 和 Codex 的能力 | 共用执行语义，保留独立适配器与运行时策略 | Codex 直接浏览需要 DSH，或者 DSH 丢失已有 Browser 操作 |
| 支持跳转、新页面与从零开始 | 区分开页、标签、文档和任务目标概念 | 开页需要旧页面、无法接管子页，或者旧元素仍被执行 |
| 兼顾 Cordis | 保留 Browser Definition、Provider 和消费方职责 | 动态插件绕过 Browser 检查，或者扩展需要另一套 Cordis |
| 先完成浏览器阶段 | 先交付通用浏览器能力与双端适配，再开放生态接口 | 完成条件依赖通用 DSH 网关、能力市场或 FC 求解器 |

### 形态分析的选择

能力分析区分技术可能性与合适的职责归属。下表逐行选择浏览器阶段的策略并说明原因，不限制各拥有者采用什么实现语言。[形态分析方法](https://www.swemorph.com/ma.html)用于比较，本地约定决定可行性。

| 维度 | 所选策略 | 原因 |
| --- | --- | --- |
| 起点 | 选定、发现或新开 | 自主浏览不以现有标签为前提 |
| 目标范围 | 独立选择单标签、后代页面或明确集合 | 用户指定的起点也可能合理地延伸到多个页面 |
| 观察 | 先结构，再按需补局部细节和截图 | 控制结果体积，同时保留复杂布局证据 |
| 执行粒度 | 一次 agent 决策配有界浏览器机制 | 减少模型反复等待，同时不嵌入网站工作流 |
| 网站知识 | 共享 skill 与调用方确定性模块 | 新业务规则不必更新浏览器扩展 |
| 状态 | 扩展保存执行日志，调用方保存任务状态 | 恢复事实与任务含义具有不同寿命 |
| 连接 | Codex 与 DSH 独立适配 | 浏览器可用性不依赖 DSH 在线 |
| DSH 扩展性 | Cordis 消费方使用既有 Browser 服务 | 保留组合、作用域权限和清理 |
| 展示 | 既有 agent 界面和通用扩展、页面投影 | 丰富展示不要求扩展执行领域计算 |

排除的组合包括：无目标启动却要求 PageRef、子页任务却永远限制在原标签、跨导航预先计算元素序列、只依赖 worker 全局变量实现持久调度，以及通过强制 DSH 转发实现 Codex 独立性。这些是一致性约束；首期不新增领域求解器则属于范围选择。

### 职责归属

| 拥有者 | 职责 | 状态权威 |
| --- | --- | --- |
| 浏览器与网站 | 真实标签、文档、frame、渲染状态和业务响应 | 浏览器会话与网站状态 |
| 扩展执行内核 | 目标检查、有界读取、输入、转移事实、回执、取消和写入冲突协调 | 有界执行日志；不承担任务规划 |
| Codex 连接器 | MCP 适配、调用方身份、能力发现和有界结果 | 已声明的连接与请求保留；不替代执行日志 |
| DSH Browser Service Provider | 将浏览器语义适配到 ctx.browser 和当前 Cordis 作用域 | 既有 DSH 授权与请求所有权 |
| DSH BrowserTask 与 agent | 目标选择、任务进度、业务检查和已授权范围变更 | Session 事实 |
| Codex agent | 目标选择、任务进度、业务检查和工具选择 | Codex 任务上下文及支持的产物 |
| 共享应用知识 | 网站概念、经验证配方和确定性计算 | 有版本的 skill（技能）或所属模块；不保存可复用的实时元素引用 |

扩展把调用方身份当作不透明标识。当前线协议名 sessionId 不会赋予 Codex 调用方访问 DSH Session 的权利。凭据、回执和恢复查询归属原连接。真实浏览器写入冲突必须跨连接检查。

## 浏览器设计决定

### 起点与范围独立

起点可以是用户选定的标签、agent 在任务授权内发现并选择的标签，或者新 URL。允许的目标范围可以是单个标签、该标签及能够关联的后代页面，或者明确选择的一组标签。当前目标是这个范围中的一个成员。选择它既不聚焦 Chrome，也不扩大站点权限。

既有用户固定单标签行为继续可用。要求打开网站并浏览详情的任务，可以选择较大的范围，无需为每次普通跳转重新确认。“这个页面”不能授权选择无关前台标签。子页关系不代表可以任意访问用户的其他标签。

DSH 在同一个 Session 所有的任务中记录初始选择和接受的转移。转移保留预算、未决请求和资源所有权；不能另建任务来绕过阻塞。Codex 在自己的环境中保存对应任务选择。双方不能改变对方的选择。

### 开页先于观察

浏览器级打开操作接收已授权安装、允许的 URL，以及调用方生成的请求身份。它不要求已有 PageRef，也不要求先附着 DOM。Chrome 返回 TabRef；扩展观察到 frame、文档和实际 URL 后，才获得 PageRef。创建标签与页面可读是两个不同事实。

即使目标仍在加载，已确认创建回执也包含新标签。创建结果不确定时，应核对原请求，不能再开一个标签。因此，开页需要无页面目标的安装级执行日志准入；普通页面写入仍须绑定目标。新标签所有权必须在已声明日志保留期内跨 worker 重启存在。

首期前提是 Chrome 安装已运行并连接。启动已停止的浏览器属于独立本地启动器。打开默认创建后台任务标签；聚焦须显式发起。自动清理仅限能够确认的任务新建标签；关闭用户已有标签需要对应用户意图。

### 引用具有不同寿命

PageRef 标识安装、标签、frame、文档和观察时的 URL。ElementRef 另外标识本次观察和元素。执行器在派发前检查身份和可操作性。选定标签可以经历导航；旧 PageRef 和 ElementRef 不能继续使用。

同文档路由或 DOM 替换导致记录 URL 或元素含义改变时，必须重新观察。frame 被替换后，其引用失效。标签丢失或浏览器重启会使实时句柄失效：记住的数字 tab id 不能恢复操作权。重连应发现并校验目标，而非选择前台标签。

### 逐层观察

首次读取返回有界正文、控件、frame 边界和页面身份。查询和稳定树分页细化观察；结构不足时由截图提供视觉证据。执行器在采集前后检查目标身份，结果跨越不相容文档变化时拒绝返回。结果标明观察时间及相关截断或遍历限制。树遍历完成不代表虚拟列表库存或服务端数据完整。

扩展报告浏览器事实。网站含义、语义摘要和覆盖判断归调用方或确定性领域模块。应用知识可以建议去哪里查看，但不能提供实时定位符，也不能证明当前库存、价格、权限或完成情况。

完整设计允许将坐标输入绑定到精确图片、视口和页面身份。首期提供截图，但不增加坐标输入 API，也不承诺纯画布自动操作。此类输入返回明确的不支持结果和可见证据。agent 不能编造 DOM 目标，也不能在未决写入存在时静默换通道绕过它。

### 执行有界机制

执行器可以把已知元素滚入视野、检查可操作性、发出一次输入、观察导航并收集有界反馈。这些确定性机制减少模型往返，同时不包含网站规则。操作具备截止时间和取消语义；超时不代表输入从未发出。

首期不增加任意远端代码加载器或通用脚本语言。更长的配方和领域计算留在 agent 环境。既有有界序列在准备好的引用或预期状态失效时停止；不能盲目复用导航前的元素。DOM 就绪或 URL 改变不证明业务完成。

### 先报告转移，再选择后续页面

一个回执可以描述多项变化：同文档更新、同标签导航、子标签或窗口创建、frame 替换、关闭或不确定转移。它包含前后目标和关联证据。来源标签事件能证明来源关系，却未必能确定并发的人类或 agent 输入中哪一次造成了变化。

直接观察到的开页可以证明精确请求所有权。唯一关联的导航可以给出已确认后续目标。多个子页、并发用户输入、延迟事件或观察丢失，保持为候选或未知。agent 选择允许的已确认目标并重新读取；候选有歧义时需补充观察，任务无法区分时再由用户选择。

新激活不等于符合意图。重定向返回受保护内容前须检查当前权限。不可访问目标不能扩大授权。登录或必须由人处理的交互应报告为任务状态，不能通过重放前一动作处理。

### 恢复执行，不虚构业务成功

容量背压明确标识在执行前被拒绝的操作，并在已知时提供已停稳写回执的最早过期时间。这只是重查提示，不预留容量，也不授权自动重试。调用方可以保留任务，并在容量可用时继续观察；在途写入仍需恢复或结算。日志容量增加或更换浏览器 profile 不是恢复契约。

每个变更性请求在派发前获得身份。扩展先持久化意图再发出操作，并在明确的数量、字节和时间边界内保留回执。日志保存恢复事实，不保存可重放动作输入。匹配的已保留身份返回原工作或回执；冲突载荷应被拒绝。保留过期后，调用方也不能重新提交已发送请求，状态查询不能执行动作。有界保留不是永久的恰好一次保证。

调用方区分 not-sent 与 sent，以及 observed、failed、cancelled 或 unknown 结果。已观察浏览器效果在网站读回前仍未验证业务结果。取消限制后续工作，不能撤销已交付输入。

仍可能执行的写入，会阻止双连接对真实标签发起冲突写入。证明完全停稳后，可以释放占用，同时保留结果 unknown。释放不允许重复结果不明的购买或提交。过期或缺失回执保持不可用或 unknown，不能证明没有产生效果。

### 人工控制与展示

用户能够检查目标、调用方、连接、任务创建的标签和未决请求。界面区分目标选择与浏览器焦点。人工导航或编辑会使受影响观察失效；恢复 agent 操作从新读取开始。

既有 DSH 对话、解读和证据视图保留服务归属。通用页面渲染和入口挂载保留精确所有者、文档和清理义务。新增网站业务面板不进入浏览器内核。显示摘要既不授予操作权，也不证明完成。

## Cordis 与未来生态接入

DSH 保留 ctx.browser 这个 Service Definition、连接扩展的 Service Provider，以及 Tool、BrowserTask 和动态 Cordis 消费方。Profile/preset 组合选择能力。转移和恢复事实经过该提供方；生命周期检查覆盖普通工具、直接提供方调用和动态插件浏览器调用。传输适配必须保留这些作用域。

动态 runner 拥有 Host 代码、Agent 身份、package/run 生命周期和受管浏览器接口。DSH Client 代码使用自己的 Client runner，不在 Chrome 扩展里新建运行时。插件停止或更新继续承担清理责任。详见 [Browser 定义](../../../../packages/browser/browser/README.zh.md)、[BrowserTask](../../../../packages/browser/browser-task/README.zh.md)和 [Cordis Host runner](../../../../packages/extensions/cordis-host-runner/README.zh.md)。

Codex 通过独立 MCP 适配器浏览，不依赖 DSH。适配器可以有不同工具分组和输出预算；能力发现必须报告实际操作与恢复支持。即使初始 Codex 适配器暴露较少操作，DSH 仍保留已有丰富操作。

未来 DSH 到 Codex 的桥接可以消费 Service Definition，或委派给真实 DSH Session。它独立于直接浏览器执行。本设计不新增通用能力注册表、任意 ctx 导出或作用域工具注册表副本。DSH 业务策略不会自动约束独立 Codex 连接。

## 首期边界

首期覆盖已运行且已授权 Chrome 安装中的交互浏览，以实际使用的 Windows 环境为准。包括选定、发现和新开的起始目标，允许的同标签和子页转移，显式多目标，有界 DOM、控件、frame 读取和截图，通用元素动作，以及双端取消和回执恢复。既有 Browser 与 Cordis 行为必须继续可用。

暂缓新增自主调度、通用 DSH 导出、领域求解器、完整网站内部数据访问、纯画布输入、浏览器进程启动和丰富侧栏重设计。未来消费方可以使用这套浏览器约定；这些新增能力不是首期前提。已有支持不被移除。

任务状态留在调用方。扩展拥有执行和临时资源。首期不承诺进程丢失后恢复任意 Codex 任务、不承诺动态 Cordis 包持久化，也不承诺恢复已不可挽回丢失的业务回执。自动重试不能掩盖这些限制。

## 基线与漂移检查

每个实现切片引用设计决定和必需场景行。执行器新增网站专用分支、增加状态拥有者、扩大权限、改变目标接管规则、改变恢复承诺，或者让 Codex 强制依赖 DSH，都需要重新审视设计。文件布局或有界内部辅助函数本身不要求重新讨论产品结果。

未决实现事实包括并发输入事件归因、跨窗口弹出页时序、worker 在创建标签与持久化之间停止后的恢复，以及 DSH 跨目标保留同一任务所需的精确 Session 变更。每项都要在对应代码改动前做定向约定发现或探测，不能据此发明降级行为。

观察的 checkout 为 6ddb5ca503da7b8a0da286a716565963efcb2f50，含相关 WIP；dirtyDiffDigest 为 not-observed。[扩展线协议](../../../../packages/browser/browser-extension/src/wire.ts)、[Codex schema](../../../../packages/mcp/browser-extension-mcp/src/schema.ts)和 [BrowserTask 实现](../../../../packages/browser/browser-task/src/index.ts)只证明源码缺口。行为验证时必须重新确认已安装扩展和 Profile 身份。

FeatureCharterReceipt browser-platform-r1 的批准状态为 proposed。范围为首期结果；输入是上文五条用户要求；设计决定是本文职责与行为章节；证据是所列源码检查。剩余缺口为上一段事实，以及全部组合、运行和行为验证。参与者、入口、权限、持久性、场景或完成条件变化，会使回执失效。

## 已考虑的替代方案

**所有任务固定在一个文档。** 简单选择无法表达首次开页或允许的子页跟随。固定标签保留为可用范围。

**网站工作流放入扩展。** 单个应用使用方便，但网站规则和算法会迫使扩展更新。共享 skill 和调用方程序更利于复用。

**每个机械子步骤都调用一次 agent。** 执行器虽小，每个调用方却要重复等待和转移处理。有界通用机制应靠近它所校验的浏览器事实。

**Codex 浏览全部经过 DSH。** 能复用 Host 状态，但耦合了可用性和拥有者。独立适配器在共用执行的同时保留各自可用性。

**先建通用生态网关。** 它能开放更多 DSH 能力，却不能解决开页、身份或转移问题。它保留为后续独立能力。

## 验收条件

矩阵定义首期完成条件。通用浏览器行分别适用于两个适配器。Cordis 行适用于 DSH；离线独立性适用于 Codex；跨连接冲突检查要求双端连接。每个适用行都需要对应行为和可观察证据；正常流程不能替代负例。受控页面用于复现时序失败，真实已安装扩展检查用于证明集成。

| 场景 | 要求的结果与独立证据 |
| --- | --- |
| 选定 A 后用户浏览 B | 双端都操作 A；目标和回执标识 A，不隐式改变焦点 |
| 没有选定页面 | 不依赖旧 PageRef 打开允许的 URL；先返回新 TabRef，再取得新 PageRef |
| 同标签导航、重定向、前进后退或重载 | 读取最终允许的文档；旧元素引用在输入前失败 |
| 同文档路由或 DOM 替换 | 更新受影响引用，并核对预期视图 |
| 点击打开一个可关联子页 | 报告来源与子页证据；只在范围内跟随，并重新读取 |
| 多个子页或人工输入 | 返回候选或 unknown；不按 active 标记猜测，不重复点击 |
| 显式多页面比较 | 页面证据独立；目标变化保留预算和未决效果 |
| iframe 或虚拟列表 | 读取已授权加载数据并标明限制；不推断库存完整 |
| 加载延迟、弹出阻止或人工步骤 | 等待有界，诚实报告缺失观察或所需交互 |
| 已发送动作丢失回复 | 查询同一请求；不重复输入；停稳前阻止冲突 |
| 开页或输入后 worker 重启 | 恢复保留事实，不再开页或输入；丢失保持 unknown |
| 目标关闭、浏览器重启或授权变化 | 旧句柄失效，拒绝未授权继续，不退回前台标签 |
| DSH 离线与双连接 | Codex 可以独立浏览；双端连接时共用真实执行冲突判断 |
| Cordis 消费与清理 | 相同提供方检查；停止作用域插件只清理其精确资源 |
| 纯画布输入 | 截图证据和明确不支持结果；不编造控件，不隐式绕过 |

必需证据层为 source-contract（定义、提供方、消费方）、generated-declaration（受影响的工具、线协议、Session 产物）、composed（DSH Profile/preset 与 Codex 连接器）、runtime-observed（已安装扩展与声明能力），以及 behavior-verified（矩阵和带网站读回的真实任务）。首期完成要求五层齐备。

本提案补充活跃的[个人浏览器助手 V2](../feature/2026-09-20-personal-browser-assistant-v2.zh.md)和[现场操作生命周期](../../implemented/feature/2026-09-12-browser-field-operation-lifecycle.zh.md)。它们关于固定目标、已交付证据、请求和清理的理由继续有效。草案不取代已实现决定，也不授权归档；被接受的变更必须在所属记录中处理冲突约定。

## 风险

浏览器事件可以证明来源标签，却未必唯一标识触发输入。夸大归因会选错子页。浏览器丢失可能破坏恢复事实。两种情况都必须明确保留不确定性。

通用机制会比点击转发需要更多扩展代码。放置取决于浏览器事实与跨站复用。站点选择器、领域预算和求解规则要求重新审视职责。

共用执行不代表 DSH Session 持久性或 Cordis 策略适用于 Codex 所有的工作。跨客户端业务保障需要独立设计，本文不作此承诺。

## 顶层完成条件

### 交付顺序与约定冻结

运行诊断分别标识 MCP 进程、relay 进程和扩展。组件版本与已加载模块路径用于区分扩展重载和连接器更换；身份缺失表示未知，不能据此认定安装过时。诊断元数据不授予浏览器操作权。扩展的两条连接统一上报 manifest 元数据，由 DSH 网关显式接收。预发布交付同时更新参与组件，不另设旧版握手分支。复用现有状态查询即可完成观察，无需新增注册表、安装器或自动进程重启。

独立 MCP 请求拥有者在 relay 派发前保留请求身份。HTTP 回包丢失时仍以该身份返回未知结果，从而能查询状态而不再次输入。relay 保留已有的拥有者、载荷与浏览器实例检查。传输失败不承诺 executed:false 或 quiescent:true；恢复只属于原 MCP 拥有者，更换该进程不会继承此前权限。

转移观察约定在 `value.transition` 中报告有界浏览器事实，与原执行结果独立。来源同时携带浏览器会话标签引用和精确页面引用。候选子页只证明 opener 关系；来源文档替换后结束子页归因窗口。执行器按当前权限检查最终观察到的 URL，不替调用方选择候选。整个观察受请求截止约束，动作返回后的额外观察最多为 250 毫秒。缺失或迟到的事件不能证明没有打开页面。

同标签任务推进只消费与已结算、已观察尝试绑定的规范回执。持久化 `targetReceipt` 记录 bootstrap 和页面推进时接纳的权限依据，普通 rebind 会清除它。推进保留预算、尝试、用户选页版本和资源所有者。文档替换能够证明其资源已消失。同文档路由变化保留各资源的原 URL，只允许按该 URL 清理精确所属资源，并复用既有路由丢弃回执。不确定执行须先按原请求恢复，再推进页面。显式子页选择与固定多页面范围要求按完整标签引用重新读取，并保留同一任务；个人部署及完整矩阵仍需各自的验收证据。

BrowserTask 页面回执单独以有界 `children` 观察保留 opener 候选，因为打开子页不要求源文档发生变化。源页面由回执确定；观察保留源标签、浏览器会话身份、候选关联和截断标记。最多保留八个候选与 4 KiB，回放执行同一检查。这些事实不推断因果，不结算 unknown 动作，也不授予读取子页的权限；选择仍由调用方明确决定，再按完整标签引用获取新快照。

用户在设计候选后要求开始后续流程。本轮沿用 browser-platform-r1 的产品结果，将实现分成以下依赖顺序；这不将尚未证明的机制视为已验收。复用决定为 adapt：保留现有 Browser 定义、提供方、双连接执行器、journal 和 BrowserTask，不增加平台运行时或通用注册表。当前相关实现包含未提交 WIP，运行中的个人扩展版本尚未确认。

| 切片 | 所属职责与依赖 | 完成证据 |
| --- | --- | --- |
| 开页与恢复 | 扩展、现有 Browser 提供方和独立 Codex 连接器；先实现无旧页面的明确 URL 创建 | 后台新标签、预先确定的请求身份、回执恢复、断线不重开、旧扩展能力缺失时拒绝；实际扩展和 MCP 完成新开、读取、点击、读回 |
| 同任务接纳目标 | BrowserTask 与工具消费方；依赖开页回执 | 安装级开页尝试归属同一任务，消耗原预算并保留未决请求；新鲜页面与原回执关联后，经 revision CAS 接纳目标；不得伪造 PageRef |
| 页面转移与范围 | 扩展报告事实，调用方选择范围内后续目标；依赖同任务接纳 | 同标签导航、子页、多个候选、人工干预、重定向和多页面比较的正负例 |
| 双端与生命周期验收 | 两个适配器、DSH Profile 和 Cordis 消费方；依赖前三项 | 全部适用场景、资源清理、重启恢复、独立网站读回与五层证据 |

无目标开页在线协议使用不带 page 的 tab_open，必须有 browser:write 和当前站点授权，并由安装声明 targetFreeOpen。它直接调用浏览器创建后台标签，返回 opened 和包含 tabId、windowId、browserSessionId 的引用；之后的读取才产生 PageRef。带 page 的现有调用继续经过精确页面检查。浏览器的 storage.session 保存会话标识，worker 重启保留，浏览器或扩展重启使旧引用失效；首次读取必须核对完整 expectedTab。该寿命依据 [Chrome 会话存储定义](https://developer.chrome.com/docs/extensions/reference/api/storage#property-session)。第二个切片完成前，不能宣称 DSH agent 已能从零完成任务。

Codex 开页由调用方在派发前指定 requestId。同连接及声明保留边界内，相同身份与载荷复用原请求，冲突拒绝。relay 丢失内存后的恢复使用现有 journal locator 只查状态。MCP 进程重启丢失调用方身份、日志过期或丢失时，保持 unavailable 或 unknown；不新增持久任务注册表，也不允许换编号重试同一不明意图。不同的明确开页意图创建独立标签，不增加安装级互斥；已有页面的冲突仍按真实标签跨连接判断。已停稳回执超过查询保留期后不可获取，过期存储条目在后续日志写入时清理。

独立审查明确了两个边界：安装站点权限不是任务意图；开页回执不是接管页面的授权。本切片只打开调用方明确提交的 URL，不自动跟随子页。后续目标接纳须保留同一任务与资源拥有者，不能通过跳过 BrowserTask、清空预算、另建任务或放宽 Cordis 页面检查实现。

页面创建和 journal 回执提交之间不是原子事务。该窗口中 worker 丢失时，没有充分证据恢复标签归属就保持 unknown，既不按 URL 猜测新标签，也不重新创建。已保留回执中的数字标签 ID 不是跨浏览器会话的操作权，后续输入仍需要当前页面身份。单条垂直路径通过只完成对应切片，首期状态仍由上文完整矩阵决定。

DSH 接纳新页面使用任务内目标，不写用户的 browser-target/change。默认 single-tab 任务的用户固定目标保持排他；显式任务范围允许在范围内选页；无用户绑定时，任务捕获该空选择的 revision，人工绑定或清除都会使旧准入失效。安装级开页尝试和首次读取仍在同一任务中分别消费一个动作预算、记录同一套尝试与回执。统一的 BrowserTask 结算方法接纳已确认创建的标签和新鲜页面；普通工具与直接 Provider 调用共用它。仅页面分支允许 PageRef，开页阶段不能伪造文档。Cordis 页面函数交付使用任务新鲜接纳的目标，并要求用户选页 revision 未变、当前验收证据和精确自有资源。任务选页本身不会转移所有权；cordis_handoff 单独执行显式交付，无需用户再次手动固定同一页面。


只读安装发现必须独立于旧任务的页面权限，否则连接变化会阻止 Agent 取得恢复所需的新鲜引用。列举不会授予页面访问权，也不会迁移任务范围。首次选页明确返回 `tab_reference_stale` 时，只有尚未接纳页面，且没有待接纳页面、资源、委派工作或未决尝试的任务才能以失败结束。旧回执和预算保持不变；替代任务必须引用更新的直接用户指令，保留输入不可重放的保护。已接纳页面或结果未定的操作仍须履行原有恢复责任。

连接恢复采用浏览器自身的生命周期钩子，不维持永久探测循环。有界的短暂重试结束后持久暂停；匹配的服务页面导航或可信扩展生命周期事件可使用原凭据尝试恢复。事件只提供检查可用性的理由，不授予权限。并发合并和持久冷却防止事件风暴或 worker 反复重启变成重复连接。若服务器静默恢复而浏览器没有事件，则明确等待下一次钩子或显式重试；原生后台监视进程不属于扩展契约。

产品边界、排除项和场景矩阵被接受，且职责不再依赖实现捷径决定后，设计才可进入实现。只有双端入口在已安装扩展上满足各自适用的矩阵行、真实任务有独立观察结果，并具备全部五层证据时，首期才算完成。文档、schema、通过的单元测试或单条演示都不能结束交付。
