# Agent Note: 浏览器语义导航与原文回源

Status: proposed

[English](2026-09-21-browser-semantic-navigation.md) | 中文

## 问题

DOM 区域、章节目录和原文摘录能够说明采集结果，却不能帮助读者理解哪些内容相关、应该深入哪里。模型概括能够组织意义，但来源编号有效并不证明概括忠实；新候选和网页变化也可能破坏已有阅读位置。

## 提案

以 Overview → Focus → Source 为阅读路径，将来源快照、语义地图和界面状态分离。Browser 在明确读取时采集有序来源块并保存私有回源锚点；Session 工具结果拥有已送达事实。模型通过有界的 `browser_read_source` 阅读完整块页，通过 `browser_publish_semantic_map` 提交引用这些块的两级导航。发布工具校验已读记录、来源、层级、版本和整体大小；网页文字不能成为指令或授权。

语义生成使用明确标记的用户回合，可重放的 Session 投影在 Host 恢复后继续识别它。Host 的单调工具守卫把该回合限制为快照、来源读取与地图发布，嵌套工具转发也受限。回合内标记只收紧权限；网页文字无法创建用户回合，后续普通回合保留原有策略。

来源和已读回执由另一个有界、仅在 Host 使用的 Session 投影拥有。事件到达时它校验调用与结果的来源，只保留近期快照，并对淘汰或变化的来源拒绝继续操作。每份来源带有快照调用时的固定目标修订号，以及已认证观察结果返回的页面身份。重新绑定、清除或后续尝试新的快照会阻止发布旧来源；同一标签的新文档观察也会使旧来源过期，但无需重新绑定。原文定位使用观察到的文档，并核对当前文字。工具执行时不再同步扫描历史 Session 事件。

每块来源保留原始次序和精确文档/快照身份。重复文本具有独立编号，代码保留空白，表格保持行顺序。段落回源先确认文档，再用保留节点与原文比较；文字被修改、节点删除、缓存淘汰或文档替换时明确失败，不按相似文本猜位置。滚动只更新已有来源的阅读位置；相关变化使定位承诺失效，不触发模型重跑。

语义地图是可替换的 AI 解读。节点引用的块必须出现在已提交来源读取结果中，未被组织的块仍可访问。来源存在与语义忠实分开验收；界面显示 AI 概括和人工核对状态，不显示模型自报的可信度。地图版本及节点身份由程序管理，新候选保留为可显式切换的版本，不无声覆盖旧图。展开、回退与定位均不重新调用模型。

本提案部分替代[个人浏览器助手 V2](2026-09-20-personal-browser-assistant-v2.zh.md)中的空间区域主视图；其会话、精确目标、权限与未知结果规则继续有效。[交付计划](../../../../docs/superpowers/plans/2026-09-21-browser-semantic-navigation.zh.md)拥有切片和验收顺序。首条完整路径是文章、教程和文档，FUTBIN 保留为列表类验收目标。

## 考虑过的替代方案

**确定性区域框作为语义地图。** 它适合证据和结构检查，无法表达内容的意义组织，因此只作为降级导航。

**一次模型调用生成图与定位器。** 这将理解错误和定位错误混在一起，也无法保证页面变化后的回源。程序分配来源身份，模型只选择引用。

**先冻结完整知识图谱分类和自由画布。** 固定观点、证据、反例的类型会限制教程与列表；未经核验的距离和关系线可能暗示不存在的因果。先验证分组导航，再按证据引入关系。

## 验收标准

真实模型从固定页面的已读块生成地图，用户经过总览、聚焦和来源后高亮正确原文，再返回相同阅读位置。切换无关标签不改变目标，展开不增加模型调用，候选版本可显式切换，错误引用和过期版本被拒绝。语义留出样本检查限定条件、数字、否定和作者归属；导航任务与目录、搜索和普通摘要比较。结构、构建、截图或模拟数据均不能单独关闭验收。

## 风险

来源校验不能证明模型解释正确。浏览器私有锚点有容量限制；旧快照可读不等于当前网页可定位。来源块和生成输出均有界，缺口必须保留。首版不承诺完整处理无限滚动页面或复杂因果，也不以文章测试代替 FUTBIN 等列表类验收。
