# Agent Note: 个人浏览器助手 V2

Status: proposed

[English](2026-09-20-personal-browser-assistant-v2.md) | 中文

## 问题

个人助手需要明确的任务目标，以及如实展示已读取内容的视图。查询前台标签及 worker 全局选中会话不能在多个窗口间保证这一点。实用页面功能也会超出创建请求的生命周期，但当前任务约定要求清理可见资源，Cordis runner 则把删除绑定到定义它的 Agent。

## 提案

以已认可的任务中心原型为 UI 规范。页面选择显式且属于会话，每个界面独立选择会话并保留草稿。Browser 与 Cordis 操作共用 Host 目标修订号和精确文档检查。页面认知来源于已送达证据，不另建自动阅读器。

只将明确交付的功能提升为现有 Cordis 注册表中已认证个人安装所有者的资源。来源会话继续作为溯源信息，后续用户命令捕获当前已授权执行作用域。临时插件仍归 Agent 所有。只有精确、经验证的所有者回执且无待定写入/清理时才移交可见资源；单个 retained 状态不能令任务完成。保持现有请求核对和清理约束。

扩展使用专用 `browser-assistant` preset 创建会话。它保留 Browser、Dynamic Cordis 和可重放压缩，包括 `/compact` 与超大工具结果裁剪，同时排除标准 preset 的 shell、文件系统和委派工具。经认证的斜杠命令执行直接寻址当前会话，无需模型往返；未匹配命令只回落为一次普通提示提交。首版保证同一 Host 进程内跨轮次、跨会话使用，不保证重启持久化。全局发现不授予 DOM 权限。页面功能在刷新/导航后需显式重跑，不自动注入。[实施计划](../../../../docs/superpowers/plans/2026-09-20-browser-assistant-v2.zh.md) 拥有任务边界、模型分工与验收命令。

## 语义页面地图

空间区域主视图由[语义导航与原文回源](2026-09-21-browser-semantic-navigation.zh.md)部分替代；下文精确目标、已送达证据和权限规则继续适用，区域框本身不再构成语义地图的交付标准。

页面认知以一个 Session 内每个精确页面文档一张语义地图作为主视图。地图保留已观察的大体布局，把已送达内容和当前操作分入各区域，并明确展示覆盖度与遗漏。浏览器观察工具会在易被 spill 的模型文本之外持久化有界且不含 selector 的结构化证据，地图从该持久结果元数据投影。概览和操作发现共用此视图；“结构”和“证据”作为次级检查视图。未知总数和有歧义的区域匹配必须明确说明。定位要求当前有效的已送达元素引用；选择区域本身不能授予网站操作权限。

页面地图是确定性证据展示，不是截图仿制品，也不是权威的模型摘要。通用语义角色和集合模式适配不同网站；只有重复证据证明通用投影损失重要结构时，网站适配器才可增强名称。任何展示器都不能改变目标权限、定位有效性、操作策略或已知与未读状态。

后续功能遵守放置规则：跨网页的一眼信息进入地图，选中区域的细节进入检查器，原始生命周期或 DOM 事实进入“证据”或“结构”。只有独立用户任务无法由这些层表达时才增加认知一级视图。[语义页面地图计划](../../../../docs/superpowers/plans/2026-09-21-browser-assistant-semantic-page-atlas.zh.md) 冻结投影、交互、交付及演进规则。

## 考虑过的替代方案

**只在 UI 固定目标并标记保留。** 这无法约束 Browser/Cordis 分发，也不能证明另一所有者仍能停止已交付功能。

**单个全局目标或全局可操作插件目录。** 第二窗口或会话可能重定向任务，或仅通过发现功能就取得控制权。会话绑定与经过认证的显式功能命令保留个人工作流，不引入新授权向导。

**只有销毁页面 UI 才完成任务。** 这适合临时检查，却违背持续使用交付物的目标。经验证的责任移交允许持续使用，同时保留清理责任。

## 验收标准

真实扩展/模型任务在用户浏览 B 时操作固定的 A。页面认知对应实际送达内容，且不因无关变化刷新。真实创建的功能在新对话后仍可使用、接受明确授权的修改，并在停止后有可观察清理。会话流、替换和重同步不重复显示或重放工作。计划中的五个必需证据层和独立审查决定是否完成。

## 风险

错误提升可能削弱跨会话权限或遗留清理；精确安装/功能/运行所有权及负向测试是必要条件。进程内状态可能在 Host 丢失时消失，不能称为持久化。本提案补充但尚未替代已实现的[现场操作生命周期](../../implemented/feature/2026-09-12-browser-field-operation-lifecycle.zh.md)，其中请求与清理不变量继续有效。此未实现提案尚未完全替代任何现有记录，也不构成归档条件。
