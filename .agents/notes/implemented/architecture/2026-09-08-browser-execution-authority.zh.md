# Agent Note: 浏览器执行授权与恢复

Status: implemented

[English](2026-09-08-browser-execution-authority.md) | 中文

## 问题

浏览器操作作用于用户已经打开的文档。前台标签会变化，扩展后台会重启，响应丢失也不能证明页面效果没有发生。复用[内容导入授权](../feature/2026-09-07-browser-content-import.zh.md)，还会把保存指定文本的权限扩大为操作已登录网页的权限。

## 决策

[浏览器包组](../../../../packages/browser/README.zh.md)区分服务定义、Host 扩展提供方和 Chrome 执行运行时。它在已有凭据提供方中保存每个安装的独立浏览器授权，与 Web Cookie 和内容导入分离。已登录的所有者批准所申请权限的子集。撤销在异步凭据写入完成前使派发许可失效；替换授权递增代次，每条活动连接和请求均须匹配该代次。

[子系统契约](../../../../docs/subsystems/browser.zh.md)把操作绑定到会话、安装、标签、框架和 Chrome 文档身份。快照元素保存隔离世界中的 DOM 对象引用及其动作相关属性。包括导航在内的页面命令均面向记录的文档；新切换到前台的标签不会接收之前的操作。

Host 为当前调用方维护有界请求表。Chrome 在派发页面效果前持久化最小执行意图，并将有界回执与动作输入分离。结果未知的写操作锁定整个标签，跨越扩展后台、Host 重启、会话和授权变化。已初始化的日志缺失时拒绝执行。重连查询状态，不重放原动作。取消请求当前执行器停止；确认解除未知写锁前，必须证明旧操作不能再发出动作。

内容导入保留独立的数据与授权契约。浏览器执行本身不提供模型工具暴露、语义审批策略或对话历史所有权；这些消费者必须使用各自负责的服务。

模型工具消费方通过原生 Agent 生命周期维护有限的观察、操作与验证任务；续步作为插件消息进入 Session 日志。机器成功条件必须使用新观察；独立的动作与续步预算限制重试，结果未知时终止任务且不重放。完整 DOM 快照使用保留的树游标与精确节点引用，过期或语义变化使旧目标失效。这些机制支持可追溯的纠错，无需第二套模型循环，也不静默重新绑定选择器。

## 考虑过的替代方案

**复用内容令牌或 Web Cookie。** 两者都会将已有授权扩大到原定用途之外。独立安装授权保留独立撤销能力，并向所有者明确展示申请的浏览器访问范围。

**重连后重放动作。** 回执消失前，页面可能已经完成点击或提交。持久身份与状态查询保留这种不确定性，不产生第二次效果。

**仅在 Host 保存写锁。** Host 重启会丢失内存请求表，而文档可能仍在执行。扩展是共同的执行所有者，负责可跨重启保留的写锁；Host 请求表用于提前拒绝冲突。

**在当前标签重新解析选择器。** 从观察到执行之间，活动标签与匹配的 DOM 节点都可能变化。绑定文档的对象引用拒绝过期目标，不会把旧意图转移到新元素。语义快照搜索和分页返回新的精确引用；工具在操作或准备过期后读取一次有界快照，让模型检查结果并选择新目标，不静默重新绑定或重放写操作。代价是一次读取与额外工具结果上下文；反馈不可用不会覆盖原操作结果。

**普通 DOM 操作一律使用 debugger/CDP 会话。** 经验证的 DOM 路线无需调试器权限或处理调试器附着冲突，即可覆盖显式读取与有界动作。普通文档执行无法满足具体操作时，再独立选择增强执行能力。

## 结果与影响

授权、通道、日志与 DOM 测试约束授权和恢复边界。隔离的真实 Chrome 验收通过实际扩展后台连接构建后的 Web Profile，覆盖回执丢失、重启、过期引用、导航核验和取消。该选择放弃自动重试恢复：执行器不可用时，标签可能持续禁止写入，直到可以证明执行已经停止。独立授权与小型持久日志增加了状态，但使浏览器效果不依赖 Web 界面或 Host 调用方的生命周期。
