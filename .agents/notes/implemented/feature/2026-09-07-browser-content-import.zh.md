# Agent Note: 浏览器内容导入

Status: implemented

[English](2026-09-07-browser-content-import.md) | 中文

## 问题

用户需要把打开网页中的有用材料保存到既有 Content 内容库，而不必手工粘贴。浏览器扩展能看到 DSH Host 无法看到的页面内容，但它不能继承 Web 会话、向页面脚本暴露持久凭据，也不能建立第二套内容存储。同一种连接模型还需要在 DSH 运行于本机、局域网 Host 或远程服务器时保持成立。

## 决策

Chromium 扩展采集普通网页中的当前文本选区、ChatGPT 中的一条已结束助手回复，或知乎中一条已展开回答。它把文本、标题、URL、站点、采集时间、范围和可选的外部消息身份发送给 `@changanhua/dsh-content-browser` Host 桥。Content 在一次 `save-text` 操作中共同持久化正文与明确标记为未经验证的 `web-page` 来源。UUID 采集身份同时映射到 `web:<captureId>` 和 operation ID，因此响应丢失后可以重试而不产生重复条目。

每个扩展安装使用保留的 verifier 和 SHA-256 challenge 创建独立连接请求。在已登录 Web 应用中打开请求只展示请求；用户必须显式批准。桥把 verifier 兑换为仅含 `content:import` 权限的 bearer capability，只在凭据 Provider 中保存严格版本化的令牌哈希，并且只向精确匹配的扩展 Origin 返回秘密。内容脚本和侧边栏都不会收到该 capability。撤销、替换、请求中止和服务 dispose 会在 Content 提交前再次使已经进入通道的导入失效。

扩展接受 HTTP(S) origin 根路径作为 DSH 地址。因此协议以同一约定连接本地、局域网或服务器 Host。当前路由形状不支持部署路径前缀，远程运行方负责配置可信 authority 与传输安全。待批准握手保存在 Host 内存；已批准授权、导入回执和 Content 条目使用各自所有方的持久化能力。

提取范围有意保持很小。ChatGPT 回复和知乎回答以外的适配器、自动爬取、整页清洗、远程来源获取、语义处理、同步和自动提升信任都不属于此功能。未来适配器可以在同一版本化导入边界后增加采集形状，而不改变 Content 所有权或安装 capability 模型。

日常收藏发生在被选材料旁或选区右键菜单中。单一侧栏拥有阅读预览和恢复操作；设置处于次要位置，默认并记住本机 3080 地址。受信任的扩展控制器在授权或发送前持久保存一份待处理快照。已经尝试发送的请求在明确持久结果之前保持不可变；尚未发送的草稿可显式丢弃。连接恢复本身不会开始上传。有数量上限的回执链接使先前页面按钮能打开对应条目，而不缓存第二套内容库。

## 验证

自动化浏览器验收驱动已解压扩展、构建后的 Web 应用、批准界面、普通选区和 ChatGPT 形状的单回复 fixture，覆盖导入、编辑、Host 重启与授权撤销。手动验收还在真实 ChatGPT 对话和普通网页上运行已安装扩展，覆盖预览、导入和打开已保存的 Content 条目。远程 HTTPS 部署仍未验证。

## 考虑过的替代方案

**让扩展复用已登录 Web 会话。** 这会把扩展耦合到浏览器 Cookie，并给导入的页面代码更大的权限边界。独立安装 capability 让批准和撤销保持显式，并把凭据限制为内容导入。

**运行仅限 localhost 的原生辅助程序。** 原生辅助程序会让本地 DSH 更方便，但 DSH 移到局域网或服务器后会造成产品分裂。HTTP(S) Host 桥让三种部署位置共用一种连接约定。

**让 Host 获取并提取每个 URL。** 需要认证的页面、动态视图和用户当前选区往往不存在于服务器获取结果中。扩展拥有提取职责；Host 把扩展提供的来源记录为未经验证。

**创建浏览器专用内容存储。** 第二套存储会割裂搜索、阅读、持久化和重试行为。浏览器导入通过 Content 的公开 mutation 进入既有 Content 领域。

**每次采集都要求经过预览表单。** 阅读网页已经完成了常见情况下的内容检查。就地操作和合理默认值保持阅读连贯；需要检查范围、标题或恢复失败时，侧栏仍可使用。

## 后果

已交付的纵向切面使用真实扩展和 Web UI 验证了显式连接批准、持久导入、Host 重启恢复、普通选区采集、ChatGPT 单回复采集、Content 编辑和授权撤销。它获得了一套内容库，以及跨 Host 部署位置的一种连接协议。它也接受这些成本：采集文本由用户代理提供，远程安全依赖部署配置，Host 重启后待批准请求必须重新发起，新增站点适配器需要各自的 DOM 兼容性证据。
