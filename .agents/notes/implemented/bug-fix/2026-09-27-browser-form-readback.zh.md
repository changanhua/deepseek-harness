# Agent Note: 显式表单值回读与浏览器定向读取

Status: implemented

[English](2026-09-27-browser-form-readback.md) | 中文

## 问题

省略所有输入值会让 Agent 无法将准备好的表单与用户指定文字比较。只过滤控件却保留整页正文，也会给定向读取增加无关内容。

## 决策

[独立 MCP 连接器](../../../../packages/mcp/browser-extension-mcp/README.zh.md)与 [DSH 浏览器工具](../../../../packages/browser/tool-browser/README.zh.md)通过 `includeValues` 提供明确启用的当前 input/textarea 值读取。共用的扩展读取器保留空白，标明截断或脱敏，并让输入值继续排除在默认读取、后台观察和查询匹配之外。密码、文件、隐藏输入框及 autocomplete 标明的凭据或支付信息仍然排除。未标记字段不保证不含敏感信息；由调用方选择目标表单。

查询将正文与结构限定在本次返回控件最近的局部容器内，范围随控件分页变化。`textScope` 明确说明覆盖范围。省略查询时仍可读取整页。已有准确引用可用于稳定表单中的连续输入；提交前核对要求重新完整回读输入值。

本决策补充[浏览器执行权限决策](../architecture/2026-09-08-browser-execution-authority.zh.md)，权限、身份和未知操作恢复继续由该文档定义。本决策实现[平台提案](../../proposed/architecture/2026-09-26-browser-capability-platform.zh.md)中的观察选择，不代表完成提案中的任务范围工作。两个记录都保留独立理由，均未被取代。

## 考虑过的替代方案

**每次快照都暴露输入值。** 这会让日常观察超出 Agent 打算检查的表单。显式读取保留默认省略行为，并限制增加的内容。

**每次表单核对都使用截图。** 图片适合检查布局，但不能提供精确的多行文字或明确的字段截断标志。结构化值支持确定性比较。

**过滤控件时仍保留整页正文。** 这会隐藏范围不一致，并保留促使调用方使用定向读取的输出成本。明确局部范围能让证据缺口可见。

## 后果

调用方必须区分空值与省略、脱敏、截断值，不能用局部查询推断整页不存在目标。输入值共享文字预算；单独查询字段可以补读被前置字段挤占预算的值。超过整次预算的单个字段仍不完整。DOM 与连接器测试覆盖当前值、查询范围、隐私标记和分页；隔离 Chromium 通过构建后的 MCP 调用，对真实表单状态核验引用复用。个人已安装进程需要另行启用新发布版本，源码改动才会在线生效。
