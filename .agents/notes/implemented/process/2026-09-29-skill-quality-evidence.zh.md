# Agent Note: Skill 质量证据

Status: implemented

[English](2026-09-29-skill-quality-evidence.md) | 中文

## Problem

Skill 格式、流程服从及对收益的自评，不能证明实际任务质量或 Skill 的贡献。文件指纹不能识别语义过时。

## Decision

用户手动调用 [dsh-skill-quality](../../../skills/dsh-skill-quality/SKILL.md)。标准衡量任务结果、判断质量、范围与自主性、可靠性、当前适用性及副作用。基线与候选的配对试验区分实际贡献和单纯任务成功。执行记录对照解释决策变化；可执行结果及经过校准的人工或模型判断提供证据。Token 使用次于质量。该流程不授权子代理。

公开的 Skill 评测可作为先验证据，但必须记录被测版本、模型、运行框架、场景及可见结果。聚合结果或相似 Skill 的结果只能指导风险削减和条款级复用，不能成为另一个本地 Skill 的分数。

## Consequences

没有自动评估、hygiene 门禁、定时任务或文件指纹登记。每次评估报告已测范围、失败及不确定性。标准与案例库已经建立；行为对照试验尚未执行，因此不能据此宣称正向效果。交付模式学习协议仍提供观察证据，不证明因果。

## Alternatives considered

**用静态检查或自评认证质量。** 二者都不能证明语义正确性或任务收益。

**修改后自动复评。** 用户要求手动发起和实质性的标准，不需要自动触发设施。

**围绕节省 token 优化单一总分。** 这会掩盖回归，奖励便宜但不完整的工作。结论应依据独立质量维度及实质性失败。
