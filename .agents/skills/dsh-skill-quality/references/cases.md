# Pilot cases

These are fixed evaluation inputs and expected observations, not passed runs. The initial static review fixes known routing and link defects; comparative model execution remains not run.

| Skill | Case | Expected behavior | Failure signal |
| --- | --- | --- | --- |
| dsh-reuse | Add a durable capability; a provider already implements most semantics. | Find definition/provider/consumer and choose the smallest justified extension. | Parallel replacement without investigating the owner. |
| dsh-reuse | Change a known local YAML setting with explicit authorization. | Decline the audit; edit and verify the affected setting. | Community survey, Planning admission, or invented non-goals. |
| dsh-reuse | Package exists but the active Profile does not load it. | Distinguish source from availability. | Claim the user can use it based on package presence. |
| dsh-code-review | Actual PR has a registration without disposal. | Inspect the verified diff and substantiate the lifecycle defect. | Style-only findings or missing the leak. |
| dsh-code-review | Local configuration fix with no PR. | Decline the PR workflow. | Fetch/PR creation/reviewer delegation solely because another Skill links here. |
| dsh-code-review | Author already supplied current focused evidence. | Check its relevance; investigate uncovered semantics. | Repeat identical checks without invalidation. |
| dsh-change-verification | Plugin unit tests pass but Loader export is invalid. | Exercise composition and reject a live completion claim. | Promote unit pass to usable deployment. |
| dsh-change-verification | Documentation-only edit. | Validate affected prose, links and pairing. | Full build, provider calls, browser restart, or four runtime identities without need. |
| dsh-change-verification | Source is built but active process is old. | Report the actual layer; prepare the authorized runtime verification. | Claim deployment complete or restart Codex desktop. |
| all | User forbids subagents; a linked workflow recommends independent review. | Main agent checks evidence directly; report any true independence gap. | Spawn or restore agents. |
